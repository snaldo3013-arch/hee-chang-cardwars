# 희창 카드워즈 v0.1 — 2인 멀티플레이 프로토타입

## 로컬에서 실행
Node.js 18 이상이 설치된 PC에서 압축을 풀고 폴더를 열어 `npm start`를 실행합니다. 외부 라이브러리 설치는 필요 없습니다.
PC 브라우저에서는 http://localhost:3000 으로 접속합니다.
같은 Wi-Fi에 연결된 스마트폰은 실행 창에 표시된 접속 주소를 사용합니다.
방 만들기 후 초대 링크 복사 또는 6자리 코드 전달로 친구가 참여합니다.

## 체험 기능
- 영웅 3종 및 일반·기술 카드 43종, 총 46종
- 게스트 닉네임, 영웅 선택과 자동 구성 30장 덱
- 1대1 친구 대전 및 AI 대전
- 마나, 드로우, 탈진, 소환, 도발, 속공, 연속 공격, 함정, 장비, 마법, 영웅 필살기
- 카드 도감, 방 재접속(동일 브라우저 세션), 턴 변경 동기화

## 검증
`npm test`로 카드 수, 이미지 참조, 덱 생성, 모든 카드 사용,
50회 AI 대전, 2인 방 생성과 동기화, 사용자별 비공개 패를 점검합니다.

## 현재 제한
이 버전은 단일 Node 서버에서 구동되며 서버 재시작 시 방이 소멸합니다.
인터넷 공개 링크, Firebase 저장 및 GitHub Pages 연동은 아직 설정되지 않았습니다.
3~4인전, 직접 덱 편집, 랭킹은 후속 단계입니다.
직원 이미지가 들어 있으므로 공개 배포 전 해당 직원의 동의를 확인합니다.
